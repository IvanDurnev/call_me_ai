# Call Me AI

Бот-приложение для Telegram и Max, которое по `/start` показывает персонажей и открывает mini app со звонком. Отдельная команда `/heroes` открывает mini app для настройки героев: имени, описания, базы знаний, аватара, голоса и параметров OpenAI Realtime API.

## Что внутри

- `python-telegram-bot` 22.x для Telegram WebApp-кнопок
- `maxbotlib` для Max-бота и кнопок-ссылок
- `Flask` + `Flask-Sock` для HTTP и websocket
- `Flask-SQLAlchemy` + `Flask-Migrate` для хранения звонков
- `Postgres` через `DATABASE_URL`
- фронтенд миниаппа в `templates/miniapp.html` и `static/call.js`

## Быстрый старт

1. Создайте `.env` из `.env.example`.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Инициализируйте базу:

```bash
flask --app run.py db init
flask --app run.py db migrate -m "init"
flask --app run.py db upgrade
```

4. Запустите Flask:

```bash
python run.py
```

5. Для локальной разработки Telegram-бота в polling-режиме:

```bash
TG_BOT_MODE=polling python bot_polling.py
```

6. Для локальной разработки Max-бота в polling-режиме:

```bash
MAX_BOT_MODE=polling python max_bot_polling.py

Важно: polling-боты запускаются только через отдельные скрипты `bot_polling.py` и `max_bot_polling.py`.
Команды `flask ...` и запуск `run.py` больше не поднимают polling автоматически.
```

7. Для Telegram webhook-режима укажите в BotFather webhook на:

```text
https://your-domain.tld/telegram/webhook
```

Если используете secret token, тот же токен положите в `TG_WEBHOOK_SECRET`.

8. Для Max webhook-режима укажите webhook на:

```text
https://your-domain.tld/max/webhook
```

Если используете secret, положите его в `MAX_WEBHOOK_SECRET`.

## Что настроить под себя

- после обновления схемы настройка героев доступна в `/heroes`
- публичный домен для WebApp и websocket задаётся через `PUBLIC_BASE_URL`
- ссылка для открытия mini app из Max задаётся через `MAX_BOT_APP_LINK`
- `MAX_BOT_ID` сохранён в конфиге, но в текущей реализации не обязателен: для работы Max сейчас достаточно `MAX_BOT_TOKEN`
- модель Realtime API задаётся через `OPENAI_REALTIME_MODEL`

## Gunicorn

Пример запуска:

```bash
gunicorn --bind 0.0.0.0:8000 run:app
```

## Корпоративные праздничные страницы

Перед запуском обновлённого приложения подготовьте схему: `venv/bin/python -m scripts.prepare_corporate_schema`. Скрипт можно запускать повторно; он не требует локальной истории Alembic.
Он добавляет страницы компаний, регистрацию по кодам, связь звонков с компанией и счётчик неверных попыток ввода почтового кода. Предварительно сохраните резервную копию базы.

В админке откройте **Корпоративные страницы** (`/admin/corporate-pages`), создайте клиента и задайте:

- уникальный адрес вида `/company-new-year`, активного персонажа, заголовок и подпись кнопки;
- фон и логотип (PNG, JPEG или WebP, до 8 МБ каждый);
- домены корпоративной почты через запятую. Пустой список отключает этот способ регистрации.

После сохранения можно открыть страницу клиента, выпустить до 100 одноразовых кодов за раз и отозвать неиспользованные коды. Полные коды показываются только при выпуске; в базе сохраняются хеши. Скопируйте коды перед уходом со страницы. Регистрация по коду требует имени и согласия; почта для неё не нужна. Доступ сохраняется в сессии браузера. Для нового браузера понадобится новый код; вход по почте позволяет вернуться через почтовый код.

Вход по почте требует подтверждения одноразовым кодом и точного совпадения разрешённого домена. Для доставки писем должны быть настроены существующие SMTP-параметры приложения. Подтверждение корпоративной почты и выданные коды дают доступ только к соответствующей странице. Корпоративные звонки не требуют личного тарифа и не расходуют личные минуты. Выключение страницы закрывает новые входы и запуск новых звонков; текущий разговор не прерывается.

Персонаж использует существующие настройки OpenAI или ElevenLabs из раздела «Персонажи». Загрузки сохраняются в `static/uploads/corporate`; этот каталог должен сохраняться между развёртываниями. Без загруженного фона используется основной фон главной страницы (комната), с теми же настройками размытия и масштабирования.


В поле **«Инструкция по созвону»** корпоративной страницы можно добавить сведения о компании, план разговора и обязательные вопросы, например:

> Поздравь с праздником от компании «Север». По одному выясни имя ребёнка, его возраст и желанный подарок. Не повторяй вопросы, если ответ уже прозвучал. В конце поблагодари за разговор.

Инструкция дополняет основной промпт и базу знаний выбранного персонажа. Пустое поле оставляет обычный сценарий. Она применяется только к звонкам соответствующей страницы, включая OpenAI и ElevenLabs, и фиксируется при старте звонка. Редактирование влияет на следующие звонки. Ответы сохраняются в существующей транскрипции разговора; отдельная анкета автоматически не создаётся.

Для уже созданной базы повторно выполните `venv/bin/python -m scripts.prepare_corporate_schema`: скрипт добавит поле инструкции, сохранив страницы и их настройки. В ElevenLabs контекст передаётся [динамической переменной разговора](https://elevenlabs.io/docs/eleven-agents/customization/personalization/dynamic-variables); текст компании не записывается в общий промпт агента.


В оформлении корпоративной страницы доступны **«Скругление углов логотипа»** (0–200 px, по умолчанию 0) и **«Корпоративный шрифт»** (WOFF2, WOFF, TTF или OTF, до 8 МБ). Загруженный шрифт применяется к заголовку, кнопкам и форме входа только этой компании. Для русского текста нужен шрифт с кириллицей. Шрифт можно заменить новой загрузкой или удалить, чтобы вернуть стандартное оформление. Для существующих страниц поля добавляются повторным запуском `venv/bin/python -m scripts.prepare_corporate_schema`.
