# Call Me AI

Бот-приложение для Telegram и Max, которое по `/start` показывает персонажей и открывает mini app со звонком. Отдельная команда `/heroes` открывает mini app для настройки героев: имени, описания, базы знаний, аватара, голоса и параметров OpenAI Realtime API.

## Что внутри

- `python-telegram-bot` 22.x для Telegram WebApp-кнопок
- `maxbotlib` для Max-бота и кнопок-ссылок
- `Flask` + `Flask-Sock` для HTTP и websocket
- `Flask-SQLAlchemy` + `Flask-Migrate` для хранения звонков
- `Postgres` через `DATABASE_URL`
- фронтенд миниаппа в `templates/miniapp.html` и `static/call.js`

## Быстрый старт

1. Создайте `.env` из `.env.example`.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Инициализируйте базу:

```bash
flask --app run.py db init
flask --app run.py db migrate -m "init"
flask --app run.py db upgrade
```

4. Запустите Flask:

```bash
python run.py
```

5. Для локальной разработки Telegram-бота в polling-режиме:

```bash
TG_BOT_MODE=polling python bot_polling.py
```

6. Для локальной разработки Max-бота в polling-режиме:

```bash
MAX_BOT_MODE=polling python max_bot_polling.py

Важно: polling-боты запускаются только через отдельные скрипты `bot_polling.py` и `max_bot_polling.py`.
Команды `flask ...` и запуск `run.py` больше не поднимают polling автоматически.
```

7. Для Telegram webhook-режима укажите в BotFather webhook на:

```text
https://your-domain.tld/telegram/webhook
```

Если используете secret token, тот же токен положите в `TG_WEBHOOK_SECRET`.

8. Для Max webhook-режима укажите webhook на:

```text
https://your-domain.tld/max/webhook
```

Если используете secret, положите его в `MAX_WEBHOOK_SECRET`.

## Что настроить под себя

- после обновления схемы настройка героев доступна в `/heroes`
- публичный домен для WebApp и websocket задаётся через `PUBLIC_BASE_URL`
- ссылка для открытия mini app из Max задаётся через `MAX_BOT_APP_LINK`
- `MAX_BOT_ID` сохранён в конфиге, но в текущей реализации не обязателен: для работы Max сейчас достаточно `MAX_BOT_TOKEN`
- модель Realtime API задаётся через `OPENAI_REALTIME_MODEL`

## Gunicorn

Пример запуска:

```bash
gunicorn --bind 0.0.0.0:8000 run:app
```

## Корпоративные праздничные страницы

Перед запуском обновлённого приложения подготовьте схему: `venv/bin/python -m scripts.prepare_corporate_schema`. Скрипт можно запускать повторно; он не требует локальной истории Alembic.
Он добавляет страницы компаний, регистрацию по кодам, связь звонков с компанией и счётчик неверных попыток ввода почтового кода. Предварительно сохраните резервную копию базы.

В админке откройте **Корпоративные страницы** (`/admin/corporate-pages`), создайте клиента и задайте:

- уникальный адрес вида `/company-new-year`, активного персонажа, заголовок и подпись кнопки;
- фон и логотип (PNG, JPEG или WebP, до 8 МБ каждый);
- домены корпоративной почты через запятую. Пустой список отключает этот способ регистрации.

После сохранения можно открыть страницу клиента, выпустить до 100 одноразовых кодов за раз и отозвать неиспользованные коды. Полные коды показываются только при выпуске; в базе сохраняются хеши. Скопируйте коды перед уходом со страницы. Регистрация по коду требует имени и согласия; почта для неё не нужна. Доступ сохраняется в сессии браузера. Для нового браузера понадобится новый код; вход по почте позволяет вернуться через почтовый код.

Вход по почте требует подтверждения одноразовым кодом и точного совпадения разрешённого домена. Для доставки писем должны быть настроены существующие SMTP-параметры приложения. Подтверждение корпоративной почты и выданные коды дают доступ только к соответствующей странице. Корпоративные звонки не требуют личного тарифа и не расходуют личные минуты. Выключение страницы закрывает новые входы и запуск новых звонков; текущий разговор не прерывается.

Персонаж использует существующие настройки OpenAI или ElevenLabs из раздела «Персонажи». Загрузки сохраняются в `static/uploads/corporate`; этот каталог должен сохраняться между развёртываниями. Без загруженного фона используется основной фон главной страницы (комната), с теми же настройками размытия и масштабирования.


В поле **«Инструкция по созвону»** корпоративной страницы можно добавить сведения о компании, план разговора и обязательные вопросы, например:

> Поздравь с праздником от компании «Север». По одному выясни имя ребёнка, его возраст и желанный подарок. Не повторяй вопросы, если ответ уже прозвучал. В конце поблагодари за разговор.

Инструкция дополняет основной промпт и базу знаний выбранного персонажа. Пустое поле оставляет обычный сценарий. Она применяется только к звонкам соответствующей страницы, включая OpenAI и ElevenLabs, и фиксируется при старте звонка. Редактирование влияет на следующие звонки. Ответы сохраняются в существующей транскрипции разговора; отдельная анкета автоматически не создаётся.

Для уже созданной базы повторно выполните `venv/bin/python -m scripts.prepare_corporate_schema`: скрипт добавит поле инструкции, сохранив страницы и их настройки. В ElevenLabs контекст передаётся [динамической переменной разговора](https://elevenlabs.io/docs/eleven-agents/customization/personalization/dynamic-variables); текст компании не записывается в общий промпт агента.


В оформлении корпоративной страницы доступны **«Скругление углов логотипа»** (0–200 px, по умолчанию 0) и **«Корпоративный шрифт»** (WOFF2, WOFF, TTF или OTF, до 8 МБ). Загруженный шрифт применяется к заголовку, кнопкам и форме входа только этой компании. Для русского текста нужен шрифт с кириллицей. Шрифт можно заменить новой загрузкой или удалить, чтобы вернуть стандартное оформление. Для существующих страниц поля добавляются повторным запуском `venv/bin/python -m scripts.prepare_corporate_schema`.

### Семейные игры: Дурак

`/games` → «Создать комнату» открывает общий стол. Игроки сканируют QR-код
телефонами, вводят имена и получают личные руки. После подключения 2–6 игроков
ведущий запускает партию на общем экране. Поддерживаются подкидной дурак с
36 картами, добор, козырь, «Беру», «Бито», завершение партии и реванш.
Чтобы закончить партию раньше или изменить состав, ведущий возвращается в лобби.

Для игры дома запустите приложение с доступом из локальной сети:

```bash
venv/bin/python -c 'from app import create_app; create_app().run(host="0.0.0.0", port=5057)'
```

Все устройства должны быть в одной сети; откройте `/games` на сетевом адресе
компьютера. При открытии через localhost QR-код автоматически использует
локальный IP. Если выбран неверный сетевой интерфейс, укажите
`GAMES_PUBLIC_URL=http://<LAN-IP>:5057` в `.env`. На сервере можно указать публичный
HTTPS-адрес. Телефонам не требуется доступ к камере через сайт — QR сканируется
обычным приложением камеры.

Состояние комнат хранится в `instance/games.sqlite3` и обновляется атомарно,
включая при нескольких процессах сервера на одном компьютере. Отдельная миграция
основной БД не нужна. Для другого расположения файла задайте `GAMES_DB_PATH` в
конфигурации Flask. Комнаты действуют 24 часа с последнего обращения. Неактивные
комнаты удаляются при создании новых. Клиенты опрашивают состояние примерно раз
в секунду; сервер проверяет каждый ход и версию стола. Права ведущего и игроков
сохраняются в localStorage браузера, в QR-коде находится только ссылка приглашения.
После перезагрузки страницы игрок возвращается в свою руку; очищать данные
браузера во время партии не следует. При потере связи игра ждёт возвращения
участника; ведущий также может вернуться в лобби и убрать его.

Проверка правил и API:

```bash
venv/bin/python -m unittest discover -s tests -p test_durak.py
```

### Семейные игры: Импостер

В `/games` выберите «Импостер» и создайте комнату. Подключаются 3–12 игроков,
каждый со своего телефона. Общий экран показывает очередь ассоциаций, подсказки
и ход голосования; секретное слово и личная роль доступны только на телефоне.
Все участники, кроме одного импостера, получают одно слово из семейного набора
в 100 слов. Роль открывается по нажатию и скрывается при сворачивании страницы.

После подтверждения готовности игроки по очереди произносят и отправляют
ассоциации (1–3 слова, до 32 символов). После каждого круга ведущий запускает
голосование или следующий круг; максимум три круга. При необходимости ведущий
может пропустить ход отсутствующего участника. Голоса принимаются тайно,
голосовать за себя нельзя. При равенстве проводится повторное голосование
среди лидеров. Повторная ничья или выбор мирного игрока дают победу импостеру.
Если импостера нашли, он получает одну попытку угадать слово за 30 секунд.
Сервер проверяет время; при истечении срока побеждает компания.

Ведущий может запустить новый раунд с тем же составом или вернуться в лобби.
Состояние хранится в той же `instance/games.sqlite3`, тип игры — `imposter`.
Общая ссылка `/games/join/<код>` автоматически открывает нужную игру;
`/games/join` позволяет ввести код вручную. Сетевые настройки совпадают с
настройками «Дурака» выше.

```bash
venv/bin/python -m unittest discover -s tests -p test_imposter.py
```

### Семейные игры: Кто из нас?

В `/games` выберите «Кто из нас?» и создайте комнату. Подключаются 3–12 игроков
по QR-коду или через общий ввод кода комнаты. Партия состоит из 10 случайных
неповторяющихся вопросов, выбранных из семейного набора в 60 вопросов.

На телевизоре появляется вопрос, а участники тайно выбирают человека на телефоне
и подтверждают ответ. Можно выбрать себя или пропустить вопрос. Ответ принимается
один раз; выбранные имена скрыты от остальных, в том числе от ведущего. После
ответа всех участников автоматически раскрываются только суммарные голоса.
Ведущий также может раскрыть принятые ответы раньше, если кто-то отошёл.
При равенстве голосов номинацию получают все лидеры; если все пропустили вопрос,
номинации не выдаются. К следующему вопросу переходят кнопкой на общем экране.

После десятого вопроса ведущий открывает итоги: число номинаций и полученных
голосов каждого участника, а также историю вопросов. Можно начать новую партию
с тем же составом или вернуться в лобби. Комнаты используют общее хранилище
`instance/games.sqlite3`, тип игры — `whos`. Голоса разных участников принимаются
одновременно; ответ от предыдущего вопроса или прошлой партии отклоняется.

```bash
venv/bin/python -m unittest discover -s tests -p test_whos.py
```

### Семейные игры: Голя

В `/games` выберите «Голя» и подключите 2–8 игроков по QR-коду. Каждый получает
человечка уникального цвета. Общий экран показывает арену, имена и ярлык «Голя»
над догоняющим. На телефоне коснитесь сенсорной площадки и ведите палец в нужную
сторону; отпускание останавливает движение. На компьютере работают стрелки и WASD.

Раунд начинается с трёхсекундного отсчёта и длится 2 минуты игрового времени.
Касание передаёт роль, после чего действует короткая задержка и защита от
мгновенного обратного касания. У Голи небольшое преимущество в скорости.
Итоги показывают время в роли Голи и успешные касания; лучше результат с меньшим
временем. Ведущий может завершить раунд раньше или вернуть компанию в лобби.

`/ws/games/tag/<код>` принимает авторизацию первым сообщением, без токенов в URL.
Телефоны передают направление движения, сервер рассчитывает скорость, позиции,
касания и время. Состояние арены передаётся 20 раз в секунду и интерполируется
при отрисовке. Физика и команды сериализуются в общей SQLite-базе, поэтому
разные соединения и процессы видят одну арену. Сетевые отправки выполняются
после освобождения блокировки базы. Позиции, результат и состав сохраняются
между перезапусками сервера.

Если игрок или общий экран теряет связь, раунд и его таймер встают на паузу;
после переподключения продолжаются. Устаревший ввод перестаёт двигать персонажа
через 0,3 секунды. При открытии контроллера в новой вкладке управление переходит
ей. Для публикации нужен прокси с поддержкой WebSocket Upgrade, как у существующих
голосовых звонков. На HTTPS-сайте клиент использует WSS. Тип комнаты — `tag`.

```bash
venv/bin/python -m unittest discover -s tests -p test_tag.py
```

### Семейные игры: Покажи и объясни

В `/games` доступна игра «Покажи и объясни»: рисование, объяснение и пантомима
на общем поле с личными заданиями на телефонах. Поддерживаются 2–4 команды
(4–16 человек) и режим втроём. Есть 90 собственных карточек / 540 заданий,
открытые раунды, минутный таймер, холст телефон → телевизор, проверка результата
и отмена целого хода. Результаты оценивают сами участники.
