# «Покажи и объясни»: один телефон на команду

Игра находится в `/games`, тип комнаты API — `activity`. Общий экран показывает
поле, телефоны — задания. В версии 2 играют только командами: 2–4 команды,
минимум по двое (от четырёх человек). Каждая подключает ровно один телефон
по QR-коду и вводит название команды. После хода телефон передают следующему
ведущему внутри команды. Индивидуальные телефоны для каждого участника не нужны.

## Подготовка и ход

На общем экране слева указаны количество людей в каждой команде
и первая команда. Справа одна плашка с QR-кодом, кодом комнаты
и подключёнными командами. Количество команд определяется числом телефонов;
назначать отдельных людей в команды и выбирать ведущих в интерфейсе не нужно.
Кнопка «Начать игру» одновременно сохраняет настройки и запускает партию.

1. Команда нажимает «Показать карточку» на своём телефоне и выбирает сложность: 3, 4 или 5.
2. На START выбирает одно из шести заданий карточки. На остальных клетках
   выбирает одно из двух заданий нужного типа: рисование, объяснение (👄)
   или пантомима. Различия цветов A/B не ограничивают выбор внутри типа.
   Сервер выдаёт только разрешённые задания и отклоняет выбор другого типа.
3. После выбора сложности карточка с заданиями открывается автоматически. Ведущий выбирает задание и нажимает большую кнопку «Начать». Карточка остаётся
   видимой на его телефоне во время выполнения; телевизор и соперники её
   не получают. Под словом находится кнопка «Угадано!».
4. Нажатие до серверного deadline немедленно даёт своей команде +сложность.
   Подтверждение на телевизоре, выбор угадавшего и предварительный расчёт
   не требуются. Повторная доставка не начисляет шаги снова.
5. Через 60 секунд сервер автоматически фиксирует неудачную попытку без
   продвижения. Позднее нажатие не принимается, даже если телефон показывал
   устаревшую карточку. «Сдаюсь» также завершает попытку без продвижения.
6. После успеха, сдачи или окончания минуты очередь автоматически получает
   следующая команда. Подтверждение на телевизоре не требуется. На её телефоне
   сразу доступна кнопка «Показать карточку», а на общем экране — краткий результат
   предыдущей попытки. При достижении финиша остаётся экран победы.
   При следующем круге прежний телефон остаётся телефоном той же команды;
   фактическая передача человеку происходит вне приложения.

Открытые раунды с +6 и распределением +4/+2 удалены: продвижение всегда
равно сложности. Проигрыш по таймеру относится к текущей попытке, а не исключает
команду из партии. Ответы по-прежнему оценивают сами участники.

Поле: START=0, клетки 1…48, FINISH=49. Категории циклически чередуют рисование,
объяснение и пантомиму, дополненные цветами, значками и подписями. Несколько
команд могут стоять на одной клетке; после угадывания движется только активная
команда, остальные сохраняют позиции. Достижение или превышение 49 завершает партию.
На общем экране доступна отмена последнего целого хода, включая позиции,
колоду и очередь. Начатая следующая попытка при отмене также отбрасывается.

На телефоне холст расположен сразу под словом внутри карточки ведущего.
Его разрешение 1000×1200, пропорции 5:6; на общем экране рисунок сохраняет те
же пропорции. Пока идёт рисование, на телевизоре рисунок расположен слоем
поверх всего игрового поля. После завершения попытки слой исчезает и поле
снова видно; таймер и кнопки справа остаются доступны. Нормализованные
координаты работают по всей высоте.
Для рисования доступны холст телефон → телевизор, перо, ластик, три толщины,
отмена штриха и очистка с подтверждением. Можно рисовать на бумаге. Устную речь,
корни слов и жесты программа не оценивает. При нарушении участники используют
«Сдаюсь» либо отменяют последний ход на общем экране.

## Колода и сохранение

`app/data/activity_ru.json` содержит 90 собственных русских карточек: по 30
каждой сложности, 540 уникальных заданий. Каждое состоит из одного или двух
слов; загрузчик проверяет это ограничение, полноту карточек и отсутствие
точных дублей. Сложность связана с самим заданием; коммерческие карточки,
изображения и логотипы не использованы. Наборы расширяются данными.

Контракт Card: id, locale, difficulty, tasks по шести categoryKey.
Контракт Task: id, text, isOpenRound (в новой версии всегда false).
У каждой сложности собственная очередь и сброс; при исчерпании перемешивается
только сброс. Колода и её порядок сохраняются между запросами и перезапусками.

`activity.py` содержит серверные правила и чистый расчёт движения;
`activity_types.py` — контракты; `activity.js` — интерфейс и рисование.
В комнатном API `players` — телефоны команд, а не отдельные люди.
`settings.sizes` хранит количество людей; команды сопоставлены телефонам один
к одному. `launch` принимает настройки и запускает партию атомарно.
`guessed` разрешён только активной команде в `performing`, с совпадающими
match и turn_id, строго до deadline. Его ревизия может отставать из-за
параллельной передачи рисунка; фаза, авторизация и идентификаторы всё равно
проверяются сервером. Одновременные команды сериализованы в SQLite.

Основные фазы: lobby → handoff → choose_difficulty → choose_task (только START)
→ prepare → performing → handoff / finished. Прежние сохранения в фазе board
автоматически продолжаются со следующей команды при первом запросе. Таймер основан на абсолютном
серверном deadline. На фоне и после reload время не добавляется. При
восстановлении телефон сначала показывает нейтральный экран; «Продолжить ход»
возвращает карточку и оставшееся время. Секреты фильтруются сервером.
Журнал ходов отсутствует на всех пользовательских экранах. Внутренняя история
сохраняется на сервере для отмены и восстановления партии.
Рисование ограничено 300 штрихами / 12000 точками; операции идемпотентны и
привязаны к попытке. Неподтверждённые части рисунка могут потеряться при reload.

Версия сохранения: schemaVersion=2, ruleset=show-explain-team-phone-v2.
Сохранения прежней версии несовместимы с новой механикой; они не обнуляются
молча. Интерфейс предлагает создать новую комнату, старые данные остаются
сохранёнными. Общий срок жизни комнат — 24 часа.

## Источники и проверки

Первоначальная версия была создана по пользовательскому техническому заданию
с опорой на [официальную инструкцию Piatnik №602825](https://www.piatnik.com/uploads/media/default/0001/01/d8de6a10a3c616d1162ed3c0583b31ff9e909bcb.pdf).
Версия 2 следует новым требованиям пользователя: командные телефоны, короткие
слова, видимая карточка и немедленный результат. Правила исходной настольной
игры не подменяют эти решения приложения.

```sh
venv/bin/python -m unittest discover -s tests -p 'test_*.py'
node --test tests/js/*.cjs
node --check static/activity.js
```

Проверяются минимальный состав, ограничение четырёх телефонов, выбор сложности,
приватность карточки в течение минуты, немедленное начисление, точная граница
deadline, конкурентные и повторные команды, взаимодействие рисования с кнопкой,
совместное нахождение на клетке без сдвига соперников, автоматическая очередь,
финиш, отмена, колоды и восстановление. Для локальной проверки
запустите приложение и откройте `/games`, подключив минимум два телефона.
QR должен содержать доступный им адрес локального или опубликованного сервера.

Ручная проверка версии 2: в браузере при 1280×720 лобби с четырьмя командами
поместилось целиком (высота документа 720). Проверены подключение двух командных
телефонов, короткие задания, видимая карточка во время выполнения, кнопка под
словом с немедленным +4, смена команды, рисование с передачей на общий экран,
reload с сохранением deadline и полная минута до автоматической неудачи без
продвижения. Узкий физический телефон отдельно не проверялся.

Поле настройки точности ответов и её подпись на игровых экранах удалены.
Старое поле precision в сохранении допускается для совместимости, но не
выдаётся в API; новые настройки его не содержат.
